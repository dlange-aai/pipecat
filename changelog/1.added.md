- Added `language_codes` setting to `AssemblyAISTTSettings`, exposing AssemblyAI's list-valued declared-language parameter which supersedes the singular `language_code`. A single code (e.g. `language_codes=["es"]`) pins transcription to that language, while several codes (e.g. `language_codes=["en", "es"]`) steer toward that subset while keeping code-switching among them. AssemblyAI accepts this parameter mid-session, so changing it applies to the live connection instead of reconnecting.
