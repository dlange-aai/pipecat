- Added `AssemblyAITTSService`, for AssemblyAI's Streaming TTS WebSocket API. Each sentence is sent as its own request on a single session, interruptions cancel in-flight synthesis without reconnecting, and per-word timings drive word-level `TTSTextFrame` output. Set `Settings.language` to speak a language other than English, and use `url` for the US and EU data-residency hosts. The service replaces a session before its one-hour limit, keeps an idle session open when the account sets an inactivity timeout, and waits as long as the server asks before reconnecting. See `examples/voice/voice-assemblyai-tts.py`.
