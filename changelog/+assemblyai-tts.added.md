- Added `AssemblyAITTSService`, for AssemblyAI's Streaming TTS WebSocket API. Each sentence is sent as its own request on a single session, interruptions cancel in-flight synthesis without reconnecting, and per-word timings drive word-level `TTSTextFrame` output. Set `Settings.voice_id` to speak a cloned voice from the AssemblyAI dashboard, `Settings.language` to speak a language other than English, and `Settings.model` to choose the model. The service connects to the US host by default; set `url` to `wss://tts.eu.assemblyai.com/v1/ws` to process data in the EU. It replaces a session before its one-hour limit and waits as long as the server asks before reconnecting. See `examples/voice/voice-assemblyai-tts.py`.
